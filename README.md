# 7 meses, 7 fases 🌸

Site de presente de mêsversário: uma jornada em sete fases, com contador ao vivo, quiz, linha do tempo, motivos, uma pergunta importante e uma carta.

## Como ver

Abra o `index.html` no navegador ou acesse a versão publicada no GitHub Pages.

## Como editar

Todo o conteúdo (textos, quiz, linha do tempo, motivos) fica no bloco `CONTEÚDO (edite aqui)` dentro do `index.html`.

- **Músicas**: `musica.mp3`, `musica2.mp3` … `musica5.mp3` (também aceita `.m4a` e `.weba`). Tocam em sequência; arquivos ausentes são pulados.
- **Fotos**: `fotos/abril.jpg`, `fotos/maio.jpg` … `fotos/novembro.jpg`. As que não existirem não aparecem.
- **Teste**: `index.html#4` abre direto na fase 4.

## Estrutura

```
index.html   página única (HTML, CSS e JS)
musica.mp3   trilha sonora
fotos/       fotos opcionais da linha do tempo
```
